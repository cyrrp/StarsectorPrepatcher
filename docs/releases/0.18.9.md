# Отчёт о выпуске 0.18.9

## Совместимость

На Windows и Linux поддерживаются 0.98a-RC8 и 0.98.5a-RC8. В новой ветке две таблицы RC8
заменили четыре таблицы RC3 и RC5. Для каждой платформы генератор сопоставил 2842 класса.
У старой Linux-сборки и обеих новых сборок совпадает сигнатура `CampaignEngine.advance`.
Сборщик и агент теперь различают их по типу результата `CombatEngine.getResults()`.
Порядок патчей и их области преобразования описаны в [PATCHES](../PATCHES.md),
выбор таблицы — в [COMPATIBILITY](../COMPATIBILITY.md#native-game-namespaces).
Для AoTD Scheduler Fork `1.0.14-spp13` используется bridge V10.

## Выполненные проверки

- На восьми официальных Windows/Linux JAR проверены сборщик и запущенный агент. Все четыре
  поддерживаемые сборки получили ожидаемый ID. На четырёх сборках RC3/RC5 сборщик завершился
  с ошибкой, агент оставил игру без патчей. Отдельно проверены JVM без игры и API без игрового ядра.
- На каждой из четырёх поддерживаемых сборок проверены все 73 цели, включая обратимость перевода
  имён, повторное применение и атомарный откат. Полные прогоны `verify-structural.ps1` на Windows
  и `verify-linux.sh` в Ubuntu на 0.98.5a-RC8 прошли. На каждой платформе структурная проверка
  охватила 2659 методов.
- Поставляемый агент проверен на Windows Java 17 и 27+22, в Ubuntu на Java 28-ea+13, в каждом
  случае с Faster Rendering 1.0.0 и без него. Во всех шести конфигурациях разрешены 138 классов
  мода и 73 игровые цели. На Linux реальный AoTD-форк согласовал `0xfff` и получил один сигнал
  восстановления в обоих режимах.
- Пройдены проверки установщиков Windows, shell-скриптов и содержимого player ZIP.
  Графический запуск кампании и замеры производительности в этом выпуске не проводились.

## Установка

Метаданные мода указывают `0.98.5a-RC8`. На 0.98a-RC8 лаунчер может показать предупреждение
о другой версии. Для 0.98.5a-RC3 и RC5 предназначена версия мода 0.18.8.

Архив `StarsectorPrepatcher-0.18.9.zip` занимает 2 895 149 байт. SHA-256 архива
`3f017d3886b77980d9be353badd774e5b7e58a62d73499e841a2d5722f7dbe78`.
