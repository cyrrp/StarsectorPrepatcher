# Отчёт о выпуске 0.17.1

Дата выпуска: 2026-08-03

Поддерживаемая игра: Starsector 0.98a-RC8

## Область выпуска

`0.17.1` — совместимый hotfix для Scheduler Fork `1.0.14-spp8`. В fork восстановлены
`DomainTabListener`, `DomainUIPanel` и их UI-зависимости, отсутствовавшие в JAR `spp7`; минимальная
версия AshLib повышена до 2.2.3, где custom command-tab plugin больше не инициализируется дважды.

Bridge остаётся на schema V9. Обязательная маска `0x3ff`, optional UI market-mutation bit и полная
маска `0x7ff` не изменены. Prepatcher принимает только точную пару schema/version/mask для `spp8`;
`spp7`, будущие идентификаторы и частичные declarations получают mask `0` и исходный fallback.

## Transformation surfaces и композиция

Ни один bytecode transformation surface в этом выпуске не изменён. Порядок transformer groups,
matchers, mutation plans, postconditions и rollback semantics совпадает с `0.17.0`:

- exact market-open, Cargo и LOOT call-site guards;
- atomic UI market-mutation group для policy, trade, free-port и пяти industry branches;
- read-only market UI wrapper и Nexerelin `showDefenses()` child-loader path;
- clean `BaseIndustry.getMaxDeficit()` wrapper и startup loader topology.

Единственное runtime-изменение — точная строка поддерживаемой owned-fork версии в loader-safe
bridge. Поэтому новых пересечений surfaces и новых capability switches нет.

## Owned AoTD fork

Scheduler Fork `1.0.14-spp8` остаётся first-class implementation. Его стандартные economy steps
глобальны, а exact-site UI actions проходят через прежний public final dispatcher. Проверка real
fork JAR должна подтвердить:

- marker `PrepatcherContract.FORK_VERSION = 1.0.14-spp8` и bridge schema V9;
- точную declared mask `0x7ff` и required mask `0x3ff`;
- сохранённые virtual global fallbacks для rejected/error/unsafe paths;
- отсутствие unsafe future overrides на оптимизированных surfaces;
- наличие `DomainTabListener.class`, `DomainTabListener$1.class` и `DomainUIPanel.class` в поставке.

Compatibility state остаётся loader-safe: bridge не удерживает `Class`, `Method`, `ClassLoader`,
campaign objects или mod instances.

## Проверка

Полный `verify-structural.ps1` завершён успешно за 28,3 секунды:

- documentation consistency: версия `0.17.1`, 28 Markdown-файлов, 83 относительные ссылки и 71
  patch scenario;
- structural composition/order/idempotency, runtime и actual-javaagent smoke завершены без
  failures;
- real AoTD fork `1.0.14-spp8`, Nexerelin, XStream, startup, hyperspace и Faster Rendering
  loader-topology gates пройдены;
- итог verifier: `Documentation/structural/runtime/hyperspace/startup/FR verification completed`.

Отдельный AoTD release gate подтвердил обязательные Domain class entries. JVM linkage smoke
загрузил и создал `DomainTabListener`, загрузил `DomainUIPanel`, а `jdeps --missing-deps` не нашёл
отсутствующих зависимостей в восстановленном Domain/Star Systems/Warehouses graph. Остались только
ожидаемые compile warnings о `sun.misc.Unsafe` и unchecked operations. Raw output хранится только в
`.build/reports/`.

## Упаковка и обновление

Поставка сохраняет одну верхнюю директорию `StarsectorPrepatcher/`, содержит весь tracked payload
и проверяется по `SHA256SUMS.txt`. Для обновления нужно заменить предыдущую директорию Prepatcher и
одновременно установить Scheduler Fork `1.0.14-spp8`; смешивать Prepatcher `0.17.0`/fork `spp7` с
новой половиной пары нельзя.

Принятый остаточный риск не изменён: неизвестные или изменённые bytecode shapes fail closed либо
сохраняют исходный global path согласно текущему compatibility contract.
