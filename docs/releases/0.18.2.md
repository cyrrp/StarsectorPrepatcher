# Отчёт о выпуске 0.18.2

Дата выпуска: 2026-08-11.

## Назначение

Это парный выпуск для AoTD Scheduler Fork `1.0.14-spp12`. Оба мода нужно
обновлять вместе: runtime bridge намеренно принимает только точный идентификатор
fork-версии.

Prepatcher `0.18.2` возвращается к проверенному набору transformer/runtime-изменений
из `0.18.0`; по существу меняются release identity и точно принимаемая версия AoTD.
Экспериментальная scheduler/trade-архитектура AoTD `1.0.14-spp11` в эту пару не входит.

## Совместимость

- Starsector `0.98a-RC8`;
- Java 17;
- Scheduler Bridge V10;
- AoTD Scheduler Fork ровно `1.0.14-spp12`;
- required capability mask `0xbff`, declared/full mask `0xfff`.

Сохранён restore-completion hook из `0.18.0`: AoTD перестраивает supply/demand только
после завершения восстановления industries, а временно неготовые данные не
превращаются в NPE.

## Основание отката

На одном и том же сохранении и игровой сцене возврат к доказанному pipeline поднял
наблюдаемую частоту кадров примерно с 50 до 90. Поэтому этот выпуск не пытается ещё раз
исправить контрольные точки, proof-объекты и перезахваты: он удаляет эту схему целиком.

## Проверки

Перед публикацией успешно пройдены:

- сборка agent/bootstrap JAR и обновление SHA-256 manifest;
- structural/bytecode inventory gate в `verify-structural.ps1`;
- contract negotiation с реальным JAR AoTD `1.0.14-spp12`;
- regression-набор трансформаций и runtime bridge.
