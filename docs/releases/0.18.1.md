# Отчёт о выпуске 0.18.1

Дата выпуска: 2026-08-10.

Статус: отозван; заменён парой Prepatcher `0.18.2` + AoTD Scheduler Fork
`1.0.14-spp12`.

Prepatcher `0.18.1` принимал только AoTD Scheduler Fork `1.0.14-spp11`. Эта пара
ввела в fork семантические checkpoint незавершённых economy tasks, dedicated
materialized-input generation, proof-gated trade publication, stale-proof recapture и
downstream-only skip в повторном market pass.

На большой кампании эта схема привела к стабильной регрессии игровой
производительности. Поэтому `0.18.2` не продолжает ремонт этой архитектуры, а
возвращает точный runtime-контракт к доказанному pipeline до `spp11`.

Единственное независимое изменение `0.18.1` — исключение build/release-копий
AoTD JAR из diagnostic discovery — осталось в истории, но не включено в rollback-agent
`0.18.2`, чтобы не смешивать независимые изменения с проверенной парой.
