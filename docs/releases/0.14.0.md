# Отчёт о выпуске 0.14.0

Дата: 2026-07-28. Поддерживаемая версия игры: Starsector 0.98a-RC8.

## Область выпуска

Выпуск завершает два первых этапа аудита синхронных economy-step из UI:

- Read-only UI patch удаляет доказанные `tripleStep()` из Command/Colonies, Commodity Detail V2,
  legacy Commodity Detail и уже материализованного defense view;
- Market-open patch локализует открытие настоящего vanilla-рынка и coalesces немедленный Cargo refresh.

## Vanilla market-open localization

`CampaignEngine.reportPlayerOpenedMarket(MarketAPI)` по-прежнему выполняет callbacks и публикует
`currentlyOpenMarket`, но его точный stock-vanilla `Economy.nextStep()` заменяется синхронным
refresh только открываемого рынка:

1. exact replay накопленного scheduler debt до UI cut;
2. `updatePrevStability()` и refresh администратора;
3. повторное применение conditions/industries;
4. локальный пересчёт max supply/demand и demand-class propagation;
5. stockpile/price refresh;
6. commodity-listener boundary;
7. второй локальный reapply, immigration одного рынка и economy-listener boundary.

Глобальный `CommodityMarketData` не перестраивается: UI использует последний committed snapshot,
как и поддерживаемый AoTD single-market path. Следующий `Cargo` constructor `tripleStep()`
пропускается только один раз, если совпадают exact economy/market identity, campaign thread и
локальный fingerprint. Ссылки в token слабые и очищаются при consume, mismatch, epoch change или
ошибке.

## Fail-closed контракт

Activation требует независимого подтверждения финального bytecode двух классов:

- `Economy`: exact Reach field/getter, null-params delegate, default UI params,
  `updatePrevStability`, Reach dispatch и stockpile helper;
- `ReachEconomy`: admin refresh и неизменный порядок `MainWorkTask2 → UpdateMarketsAgainTask →
  ImmigrationTask → FinishEconomyUpdateTask` с четырьмя drain loops.

Дополнительно runtime требует exact классы/loader, текущую sector economy, identity membership
рынка и отсутствие condition-only semantics. Любое несовпадение оставляет оригинальный
`nextStep()`/`tripleStep()` активным. Частичная локальная ошибка также fail-open: исходный global
step выполняется сразу после неё и восстанавливает согласованное состояние.

## Проверки

Поставка включает:

- raw и post-structural contract tests для `Economy`/`ReachEconomy`;
- future-bytecode fail-closed fixtures для обоих классов;
- ASM BasicVerifier для market-open и Cargo transformations;
- one-shot identity/fingerprint/thread runtime test;
- actual-javaagent smoke для двух contract gates и всех UI transformers;
- полный structural/documentation/checksum gate.

## Остаточный риск

Локальный vanilla pipeline воспроизводит наблюдаемые UI boundaries, но не публикует новые global
market-share/internal-trade records до штатного economy tick. Это намеренно: открытие UI не является
топологической или товарной mutation boundary. Моды, которые неявно рассчитывают на глобальный
rebuild именно от открытия рынка, должны отключить `patch.vanillaMarketOpenLocalization` или будут
автоматически сохранены fail-closed, если заменяют stock economy classes.
