# Отчёт о выпуске 0.16.0

Дата: 2026-07-29
Поддерживаемая игра: Starsector 0.98a-RC8

## Область выпуска

Выпуск расширяет единый UI mutation context affected-commodity refresh для exact vanilla trade
transaction и free-port mutation, а также тем же loader-neutral payload для поддерживаемого AoTD
Scheduler Fork. Local-policy paths сохранены без изменения семантики.

## Targeted commit

Targeted означает `все рынки × несколько affected commodity IDs`, а не обновление только одного
рынка. Локальные industries/conditions и stockpile/price state открытого рынка обновляются сначала;
затем для каждого affected ID создаются global и econ-group `CommodityMarketData`, после чего
публикуются соответствующие listener boundaries.

Trade affected IDs извлекаются только из immutable bought/sold cargo `PlayerMarketTransaction`.
Free port использует before/after commodity vector; пустой diff расширяется до всех commodity IDs
рынка. Payload нормализуется в отсортированный deduplicated `String[]` и не удерживает игровые
commodity/market объекты.

## Fail-closed границы

Оригинальный `doubleStep()` или `tripleStep()` сохраняется при любом из условий:

- final vanilla `CommodityMarketData` не проходит structural contract;
- economy или market не являются exact stock-классами;
- AoTD V9 capability не согласована;
- thread, identity, campaign/economy epoch или one-shot context не совпадают;
- payload пуст, повреждён или содержит topology scope;
- setter/callback завершился исключением.

Administrator assignment, structural industry mutations и custom providers в 0.16.0 не
локализуются. Их UI lifecycle требует отдельного exact-site transaction contract; долгоживущий
ThreadLocal между UI frames намеренно не используется.

## AoTD

Scheduler Bridge schema V9 добавляет `consumeUiMarketMutationPayload(Object)`. Fork
`1.0.14-spp6` принимает packed reason/scope и immutable affected IDs, выполняет локальную
материализацию задач одного рынка и filtered `AoTDCommodityMarketData` rebuild. Обязательный
production mask остаётся `0x3ff`; targeted capability optional. Старые V6-V8 fork contracts
остаются fail-closed совместимыми и используют исходные global steps.

## Проверка

Выпуск проверяется полным structural/runtime gate, exact trade call-site gate, final vanilla
commodity contract gate, actual-javaagent smoke, AoTD V9 payload/capability smoke, checksum manifest
и ZIP integrity test. PowerShell scripts синхронизированы с Linux gate.
