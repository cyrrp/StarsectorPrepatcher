# Отчёт о выпуске 0.13.0

Дата: 2026-07-27.

## Кратко

Выпуск устраняет оставшиеся синхронные паузы AoTD при открытии рынка, убирает холодную
материализацию глобальной commodity model из Local Resources и добавляет owner-local индекс
`ReachEconomy.getMarketsInGroup()`. Поддерживаемый Scheduler Fork выпускается согласованным пакетом
`1.0.14-spp2` и требует Prepatcher `0.13.0`.

Все optional AoTD-решения проверяются на реальном `AoTDToolboxTheory.jar`. Неизвестная или будущая
реализация сохраняет исходный путь только для несовместимого concrete runtime class; vanilla-патчи
при этом не отключаются.

## Single-market UI economy refresh

Телеметрия крупной кампании показала два последовательных synchronous stalls около 5.3 секунды:
первый при `CampaignEngine.reportPlayerOpenedMarket(MarketAPI)`, второй при Cargo `tripleStep`.
Vanilla вызывает `Economy.nextStep()` до присваивания `currentlyOpenMarket`, поэтому форк выбирал
all-market branch, полностью вычерпывал `MultiFrameTask` и затем почти повторял ту же работу.

Prepatcher публикует аргумент открываемого рынка до raw body в loader-neutral campaign-thread
context. Ссылка потребляется один раз, очищается сразу после consume и повторно в `finally`;
вложенный вызов восстанавливает parent context, а несовпадающий token очищает весь `ThreadLocal`.
Форк выполняет локальную committed sequence:

```text
selected market administrator refresh
→ local materialized/price main task
→ local reconciliation
→ singleton immigration
→ singleton post-immigration trade snapshot
→ conditional local price follow-up
→ one economyUpdated listener boundary
```

UI path не запрашивает полный список рынков, не создаёт `AoTDCommodityMarketData` для
`commodity × (global + econGroup)` и не открывает global internal-trade cut. Последний остаётся на
штатной economy cadence. Следующий Cargo step пропускается только при неизменных campaign/economy
epochs, registry/global-dirty/market-dirty revisions, identity рынка и отсутствии pending derived
work.

Coordinator принадлежит конкретному `AoTDEconomy`, помечен `transient` и хранит только primitive
revisions, identity hash и строковый market ID. Static cache по campaign objects, optional
`Class`/`Method`/`ClassLoader` или экземпляру мода не добавлен.

## Economy hot paths

`patch.localResourcesNoColdMarketData` атомарно меняет две поверхности
`LocalResourcesSubmarketPlugin`:

- `getStockpileLimit(CommodityOnMarketAPI)F` использует stateless shipping capacity без вызова
  lazy `CommodityOnMarket.getCommodityMarketData()`;
- `shouldHaveCommodity(CommodityOnMarketAPI)Z` читает уже опубликованное committed state;
- exact `AoTDCommodityOnMarket` использует loader-safe accessor к `AoTDSupplyDemandData` и тот же
  raw-unit calculation script, включая границу positive raw → zero converted;
- отсутствие committed state, изменённый data type или будущий override сохраняют raw getter.

`patch.economyGroupIndex` оборачивает
`ReachEconomy.getMarketsInGroup(String)List` и authoritative add/remove/group mutation surfaces.
Transient owner-local ordered index перестраивается по primitive epoch; source identity/size
validation и bounded ordered audit обнаруживают прямые изменения. Каждая выдача остаётся fresh
mutable list, unknown keys не накапливаются.

Exact `AoTDReachEconomy` использует inherited optimized read path, пока critical methods остаются
vanilla-owned. Реальный JAR дополнительно подтверждает один `super.addMarket()`; будущий critical
read override безопасно возвращается к raw path, а mutator без `super` обнаруживается
validation/audit без ложного обещания немедленной epoch-инвалидации.

## Fork-owned construction boundary

`AoTDConstructionSite.setAssignedWonder(String)V` имеет собственную поддерживаемую реализацию.
Exact transformer сохраняет исходное тело в private synthetic raw helper и ставит
`SchedulerBridge.beforeMarketMutation/afterMarketMutation` в `try/finally`. Накопленное время
доставляется до перехода `building=false → true`, после чего немедленно публикуются
structure/industries/derived-economy dirty bits.

Изменённое будущее тело не трансформируется. Wrapper не добавляет listener, instance cache или
сериализуемое состояние.

## Transformation surfaces и порядок

| Патч | Точная поверхность | Композиция |
|---|---|---|
| основной structural plan | `CampaignEngine.set/resetInstance`, `advance`, `setFastForwardIteration`, `create/removeStarSystem` | единый `PrepatcherTransformer` применяет lifecycle, scheduler и core-worlds планы атомарно по их методам |
| early market context | `CampaignEngine.reportPlayerOpenedMarket(MarketAPI)V`, wrapper boundary вокруг исходного body | регистрируется явно после основного structural plan и анализирует его выход; методы основного плана не пересекаются с этой поверхностью |
| Scheduler bridge | `SchedulerBridge` schema V6 ABI methods, включая optional `consumeOpeningMarket()Object` | direct same-loader rewrite; старый fork без optional метода сохраняет прежний контракт |
| Grand Wonder start | `AoTDConstructionSite.setAssignedWonder(String)V`, write/call/return invariants | отдельный exact fork transformer; изменённое тело fail-closed |
| Local Resources | два метода Local Resources и общий AoTD committed-state value flow | одна атомарная mutation group с общим postcondition |
| economy-group index | `ReachEconomy.getMarketsInGroup` и связанные mutator prologue/epilogue | единый owner-local индекс; inherited AoTD path допускается только real-JAR gate |

Повторная обработка полностью преобразованных классов идемпотентна. Structural mismatch не оставляет
частичную атомарную группу; optional fork incompatibility локально сохраняет исходную семантику.

## Owned-fork compatibility

| Класс/семейство | Статус |
|---|---|
| `AoTDEconomy` / `AoTDReachEconomy` UI path | source-owned single-market реализация; проверяется напрямую на real JAR |
| `AoTDCommodityOnMarket`, `AoTDSupplyDemandData` | inherited/loader-safe optimized path при точном committed-state контракте |
| `AoTDCommodityMarketData` | inherited linear market-share path при пяти vanilla-owned critical methods |
| `AoTDReachEconomy.getMarketsInGroup` | inherited optimized path; future read override безопасно отклоняется |
| `AoTDConstructionSite.setAssignedWonder` | напрямую трансформируется как fork-owned implementation |
| `AoTDAvailableStat.advance` | inherited temp-mod optimization подтверждена one-super-call поверхностью |
| `AoTDCommodityOnMarket.reapplyEventMod` | намеренный exact no-op; отдельный removal cache не нужен |
| map/Intel/core-worlds/strategic jump/hyperspace/loading/save/combat/presentation | fork descendants на затронутых поверхностях отсутствуют; дополнительная поддержка не требуется |

## Проверка выпуска

Release gate:

- собирает agent/bootstrap с manifest version `0.13.0` и проверяет точный runtime payload;
- прогоняет documentation/version/link/checksum consistency;
- проверяет полный enabled order, combined postconditions, idempotency и negative fixtures;
- применяет early-market transformer к post-state основного `CampaignEngine` structural plan;
- проверяет exact real-fork market-share surfaces, Scheduler bridge, UI-local bytecode contract и Grand Wonder
  wrapper;
- запускает one-shot/nested/token-mismatch context runtime test;
- проверяет Local Resources и economy-group index через structural, actual-class-load,
  actual-javaagent, XStream/GC и future-override fixtures;
- запускает общие runtime, lifecycle, save, hyperspace, startup и Faster Rendering gates.
